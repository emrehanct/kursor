# Mağaza görselleri / Store graphics

Google Play için görseller. HTML kaynaklarından başsız Chrome ile üretildi (`home.html` uygulamadaki ana sayfadır).
Graphics for Google Play, rendered from the HTML sources with headless Chrome (`home.html` is the in-app home page).

Video ekranı görüntüleri temsilîdir: uygulamanın video menüsü ve altyazı katmanı, örnek içerikle.
The video screenshots are representative: the app's video menu and subtitle overlay with sample content.
